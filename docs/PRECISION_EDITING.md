# WEB CAD — v0.7.0 OFFSET／TRIM 精準編輯

本文件保留 v0.7.0 當時的編修範圍；**v0.9.0 已新增原生 ARC、ARC 徑向 OFFSET、ARC／LINE／PL 相交修剪與 ARC 裁切邊界，詳見 [原生 ARC 文件](ARC_NATIVE.md)**。本批為 AutoCAD 常用快捷指令的可運作子集。所有幾何計算採 **模型空間毫米（mm）**；以單次 Undo/Redo 保存操作。圖層鎖定與隱藏都受保護。

## OFFSET — 偏移（O / OFFSET）

1. **先選取**要偏移的直線、圓、矩形或聚合線（僅支援純直線段）。
2. 輸入 `O` → Enter；或點左側「偏移 O」。
3. 在指令列輸入 `120` → Enter（單位 mm）。
4. 在畫布上點擊原物件的**偏移一側**；青色虛線代表預覽的新輪廓。
5. 每次點擊會新增一個物件，保留來源物件與其圖層／線型／顏色／線粗，可重複建立平行偏移。按 `Esc` 結束。
6. 仍在 OFFSET 模式時，可再次輸入新的正數距離改變下一次偏移量；可輸入絕對坐標 `X,Y` 作為偏移側點。

### 幾何範例

- `LINE 0,0 → 3000,0`；距離 `120`，上方點 `1500,500` → 新線起點 `0,120`、終點 `3000,120`。
- 圓心 `0,0`、半徑 `500`；距離 `100`，外側點 → 半徑 `600`；內側點 → 半徑 `400`。
- 矩形 `0,0 → 3000,2000`，外側距離 100 → 封閉聚合線輪廓 `(-100,-100)` 至 `(3100,2100)`。
- 折線偏移使用相鄰直線的交點生成**尖角接合（miter join）**，不是圓角；過長尖角、自交、180° 折返或退化線段會拒絕產生錯誤幾何。

## TRIM — 修剪（TR / TRIM）

1. **先用 Shift＋點選**一個或多個可見的裁切邊界（直線、矩形、圓、聚合線，或包含基本幾何的單層圖塊）。
2. 輸入 `TR` → Enter；或點左側「修剪 TR」。
3. 邊界會以金色虛線標示。點擊要刪除的**直線或開放聚合線**部分。操作使用實際有限相交點，不會憑空把兩條未相交的線向外延伸。
4. 修剪後會保留剩下的左段、右段或開放聚合線子段，並保留來源圖層與物件外觀屬性。
5. 可繼續點選其他線段；按 `Esc` 結束修剪。每次修剪都能單獨 Undo/Redo。

### 幾何範例

先畫水平線 `(0,0) → (3000,0)`，再畫兩條穿過它的垂直邊界 `(1000,-500) → (1000,500)`、`(2000,-500) → (2000,500)`。Shift 選兩條垂直線 → `TR` → 點水平線的 `(1500,0)`：中心 `1000–2000` 段被刪除，保留 `0–1000` 與 `2000–3000`，垂直裁切邊界不受修改。

一條水平線穿過半徑 300 的圓，選圓作裁切邊界並點擊圓內水平線，會移除圓內那段直線，保留左右線段；**不會產生 ARC 圓弧**。

## 目前明確限制

- OFFSET 不支援圖塊參照、尺寸標註、文字、Spline、非等比例曲線；**v0.9.0 起原生 ARC 已可等距徑向偏移**。對開放／封閉聚合線僅支援直線段；不支援弧線 bulge、斜接以外的圓角／倒角接合。
- OFFSET 預覽不保證任意複雜封閉多邊形都能偏移成功；幾何驗證失敗時會提示並保持原圖面不變。向內超過矩形可容納尺寸也會拒絕。
- TRIM 在 v0.9.0 起可修剪 **LINE、開放 POLYLINE 與原生 ARC**；**不能**直接修剪完整 CIRCLE、封閉矩形／封閉聚合線，也不支援跨圖塊內部改寫、尺寸或文字修剪。
- TRIM 以被選定的邊界與目標**實際有限交點**計算；不支援 AutoCAD 的延伸模式、Fence、Crossing、投影／3D 邊界、對任意曲線的精準弧修剪。
- 在交點附近點選恰好落在兩側的判斷可能有歧義，建議點在線段中央而非交點上。
- Web CAD 仍無 DWG 原生讀寫、完整 DXF／施工版 Layout、尺寸關聯與所有 AutoCAD 指令。請勿以此原型直接出施工圖。

## 回歸驗收與格式互通

- `src/cad/precisionEdit.ts`：OFFSET／TRIM 的純幾何與圖面更新函式。
- `src/cad/precisionEdit.test.ts`：直／斜線偏移、圓內外偏移、矩形／折線偏移、兩側／單側修剪、圓與圖塊裁切邊界、鎖層／隱藏／退化形狀、JSON、Undo/Redo 與快捷指令。
- 完成幾何編輯的結果仍是既有 LINE／POLYLINE／CIRCLE 圖元，不新增專有格式欄位；因此可使用 `.webcad.json` 主檔與上一版 DXF 2000 子集交換。
- `npm test`、`npm run build` 在 PR 中自動執行。GitHub Actions 成功不代表滑鼠、觸控、外部 CAD 或精密工程圖已完成端到端驗收。
