# WEB CAD v0.9.0 — 原生 ARC 圓弧與 DXF 往返

> v0.9.0 新增幾何意義上的真正圓弧，不是以多段短直線假裝圓弧。圖面仍是 2D 原型，尺寸單位 mm，尚未完成商用 CAD 的全部功能及施工圖實測認證。

## 圓弧的資料模型

- `kind:'arc'`、`center:{x,y}`、`radius`、`startAngle`、`endAngle`，角度以世界座標 +X 軸起算，**逆時針**為正、單位 °，保留 0–360° 間的角度。
- 頭尾角可跨越 0°，例如 **350° → 20°** 表示 30° 的短弧，不是 330°；`endAngle < startAngle` 並不代表順時針。
- 圓心與半徑均採模型 mm，可平移、旋轉、複製、框選、鎖點、JSON 保存、DXF 2000 匯入匯出及 SVG 實體比例出圖。
- 不允許零半徑／零跨度圓弧；**完整 360° 使用 CIRCLE**，不可用 ARC 代表整個圓，以免格式歧義。
- JSON `version:1` 不變，既有圖面仍可開啟；此批新增可支援的 ARC 子類，舊版程式不保證能開啟含 ARC 的新版 JSON，因此建議先備份。

## A / ARC — 三點畫弧

1. 在指令列輸入 `A` 或 `ARC`，或點工具列「三點圓弧」。
2. 點起點，例如 `100,0`；點**弧線經過點** `0,100`；點終點 `-100,0`。
3. 系統解析出 **圓心 (0,0)、半徑 R100、起始 0°、結束 180°** 的上半圓，畫布中的弧線是 Canvas 真圓弧。
4. 三點共線、重合或不合法時會出現警告，不改變原圖面。
5. 點選 ARC 後右側面板可修改**半徑／起始角度／結束角度**。旋轉使用 `RO`，平移 `M`、複製 `CO`。

反向畫弧也可以：起點 (100,0)、經過點 (0,-100)、終點 (-100,0) 會形成下半圓，內部以 180° → 0° 的 CCW 角表示。這種資料儲存方式與 DXF ARC 的角度定義一致。

## TR / TRIM — 原生 ARC 修剪

1. Shift 點選要用於修剪的直線、圓、ARC、矩形或聚合線（也支援包含基本圖元的單層圖塊）；輸入 `TR`。
2. 點擊要刪除的**ARC 弧段**。運算會找出選定邊界和 ARC 的真實有限交點，以角度分割而非將弧線離散成短直線。
3. 例如：上半圓 R100（0°–180°）被 X=+50、X=-50 兩條跨越圓周的直線切割，在頂端 (0,100) 點擊修剪，保留 0°–60° 與 120°–180° **兩段 ARC**。
4. 修剪後的 ARC 仍保有原半徑、圓心、樣式與圖層，只會變更角度跨度或拆成兩段；每次操作都有 Undo。
5. LINE／開放 POLYLINE 亦可被 ARC 邊界剪斷；EX／EXTEND 可以延伸 LINE 至 ARC 的實際角度範圍，不能延伸到 ARC **不存在的圓周**。

限制：目前 CIRCLE 仍不能直接修剪成 ARC，亦不支援 ARC 自己作延伸目標、重合圓的重疊線判斷、多層巢狀圖塊、所有 AutoCAD 自動選邊界／曲線修剪模式。沒有有效交點會拒絕，不會任意移除原線。

## F / FILLET — 這次改為原生 ARC

- 仍是**先選兩條 LINE**，輸入 `F` 與圓角半徑 mm；從切點與兩線角度求出真圓心、真半徑，修剪兩條來源 LINE，新增一個 **ARC**。
- 直角範例：水平 LINE (1000,0)→(0,0) 和垂直 LINE (0,0)→(0,1000)；`F`→`100`，得到圓心 (100,100)、半徑 R100、起始 180°、結束 270° 的實際圓角。
- `F`→`0` 仍是兩線尖角接合，不建立零長弧線。
- CHAMFER 保持建立 LINE，不會受到 ARC 格式更動影響。
- **以前 v0.8.0 用 POLYLINE 模擬的圓角不會自動轉換為 ARC**。舊圖仍保持原物件與位置，需手動重畫才會成為真正圓弧。

## DXF AC1015／SVG 互通

- 匯出 ARC 使用 AutoCAD DXF 2000 `ARC` 實體：`AcDbCircle` / `AcDbArc` subclass，`10/20` 圓心、`40` 半徑、`50` 起始角、`51` 結束角。
- 匯入 DXF ARC 支援 mm/英吋等既有單位轉換，保留跨 0° 的原生角度；目前僅 2D 正常線性 OCS／世界 XY，非平面或其他法線方向依舊不支援。
- 自訂單層圖塊定義內可包含 ARC；BLOCK/INSERT 旋轉後保持真圓弧。
- SVG/PDF 列印使用真正的 `path A` 向量橢圓弧（圓形半徑相同），大於 180° 的大弧旗標可正確設定；以弧線實際四象限極值計算出圖範圍，而非把整個圓當作外接範圍。
- CI：TypeScript/Vitest、獨立 Python `ezdxf` 讀寫及稽核 ARC、CairoSVG→PDF。**程式解析通過不能取代 AutoCAD／QCAD／LibreCAD 實際匯入、編輯、另存的人工驗證**。

## 建議人工驗收順序

1. `A` → 起點 (1000,0)、經過點 (0,1000)、終點 (-1000,0)，查看是否為完整 R1000 上半圓，物件面板確認 R1000、0°–180°。
2. `A` → 點 (1000,0)、(0,-1000)、(-1000,0)，確認下半圓；再用角度 350°→20° 的外部 DXF 測試跨 0°。
3. 用 R100 半圓與兩條 X=±50 的裁切線，執行 TR、點頂端，得到兩段仍是 ARC 的剩餘弧。
4. 選兩條 1000 mm 直角線，F→100，確認 R100 而非分段折線；DXF 匯出後應可在第三方 CAD 中以 ARC 物件選取。
5. 測試 OFFSET 徑向偏移一條弧、RO 旋轉 45°、B 建立含 ARC 的圖塊，JSON／DXF 匯入後半徑與角度仍相同。
6. 以 A3 1:50 PLOT 匯出 SVG，外部向量工具確認圓弧是 SVG path；使用 PDF／印表時仍需 100% 比例檢查。
