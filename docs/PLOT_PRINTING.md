# WEB CAD — v0.6.0 定比例出圖與向量列印

> 本版新增一頁式比例出圖原型，涵蓋 A3／A4、固定比例的向量 SVG 下載，以及瀏覽器「列印 → 儲存為 PDF」。這不是完整的 AutoCAD Layout、CTB 出圖或工地施工圖驗收。

## 使用流程

1. 在繪圖區完成圖面，先使用右上「備份 JSON」保留完整可編輯主檔。
2. 點右上「比例出圖」，或在指令列輸入 `PLOT`。**v1.1.0 起 Ctrl／Command+P 保留瀏覽器原生列印，不再直接開啟 CAD PLOT**，避免快捷鍵與瀏覽器衝突。
3. 選擇紙張 **A4（210×297 mm）** 或 **A3（297×420 mm）**、直／橫向、固定出圖比例 **1:20、1:50、1:100、1:200、1:500**、黑白／彩色。
4. 系統以所有**可見圖層**的模型空間物件邊界置中圖面；不會自動把圖面縮小至可用區域。若內容超出固定比例紙張，會顯示警告並停用輸出，請改用較大比例分母或較大紙張。
5. 「匯出 SVG」下載尺寸以 mm 定義的向量圖紙，可交給支援 SVG 的設計工具檢視；「列印／儲存 PDF」會開啟新分頁並觸發瀏覽器原生列印視窗，**使用者需選擇「另存為 PDF」**。
6. 列印設定：請使用指定 A3/A4 紙張、**100% 實際尺寸**、**無邊界**、**關閉頁首／頁尾**，不要選「符合頁面大小」「縮放以符合」等自動縮放選項。
7. 輸出完成後，核對頁面尺寸、尺寸標註與圖紙下方圖示比例尺（0–1000–2000 mm），必要時列印一張實際用尺量測。

## 出圖幾何與精度

- 繪圖模型使用 mm；圖紙上的紙張座標依 `模型長度 ÷ 比例分母` 計算，例如：
  - 6000 mm、1:50 → 紙上 120 mm
  - 6000 mm、1:100 → 紙上 60 mm
  - 1000 mm、1:50 → 比例尺每格 20 mm
- 以 SVG `width="420mm"`、`height="297mm"` 等實際單位標示紙張；瀏覽器列印使用 `@page size:420mm 297mm; margin:0`。
- 物件線粗使用 SVG `stroke-width`（單位 mm），來自圖層或物件覆寫；虛線和中心線在紙上以 mm 間距繪製。
- 圖元支援 LINE／PL／REC／CIRCLE、單層圖塊（展開參照繪出實體）、TEXT、水平／垂直與對齊 DIMENSION。
- 隱藏圖層不會印出；鎖定但可見的圖層仍輸出。保留自訂顏色或強制黑白出圖。
- 自動加上圖框、圖名、紙張／比例及 1000／2000mm 圖示比例尺；單張圖紙置中模式會根據可見物件的外接矩形自動計算中心。

## 安全與內容限制

- 不會更動 CAD 原本的圖面資料，也不會將出圖選項寫入 JSON。
- 圖框空間不足時會顯示「超出」並停用下載／列印，而不是自動縮小或悄悄裁掉圖元。
- 自訂圖面名稱及文字內容均以 XML 字元跳脫輸出，避免產生可執行的 SVG 標籤。
- **PDF 不是本專案直接生成的 PDF 檔案**，而是瀏覽器的列印轉存功能；瀏覽器、PDF 驅動或印表機可能變更縮放與字型，因此需人工測量確認。
- 尚無列印視窗選框／窗口出圖、平移出圖中心、完整多頁圖紙空間、CTB/STB 線寬配置、可變紙張、輸出印表機設定檔、可靠的文字字型嵌入、PDF 圖面驗收。
- 字型使用系統 fallback；繁體中文在不同瀏覽器和 PDF 印表系統可能代字／字寬變動，會影響圖面排版。
- 曲線門弧仍是聚合線近似；本版不解決原有幾何／尺寸標註非關聯式問題。

## 自動驗證

- `src/cad/plot.test.ts` 驗證固定紙張實體尺寸、6000mm 的 1:50／1:100 轉換、線粗、虛線、隱藏圖層、圖塊、中文字、尺寸箭頭及超出畫幅的阻止。
- `.github/workflows/plot-interop.yml`、`scripts/validate_plot_pdf.py`：獨立 Python CairoSVG 將單張 SVG 轉為 PDF，再由 pypdf 驗證 A3 **420 × 297 mm** PDF MediaBox 與向量線段 **120 mm（6000mm @ 1:50）**。
- 上述自動驗證**不代表 Chrome、Safari、Windows 印表機等所有環境均維持物理精度**，仍需人工印製與檢查。

## 建議人工驗收

1. 使用室內示範圖，A3 橫向、1:50、黑白。檢查外牆、文字、標註及圖框比例尺。
2. SVG 匯入 Inkscape 或其他能顯示實際尺寸的向量工具，檢查 6000 mm 線段是 120 mm。
3. 切至 A4 直向、1:20，若超出可用圖框，確認不能下載或列印；改為 1:100 檢查回復。
4. 切換隱藏圖層和線寬，確認只有應顯示的線條出現在 SVG。
5. 列印到 PDF，確認 PDF 頁面為 A3 橫向與 100% 比例，列印實體紙張核對下方 1000 mm 的圖示比例尺。
6. 用 Chrome、Safari／Firefox（視實際使用環境）分別檢查字型與列印結果，紀錄任何縮放差異。

後續優先方向：真正的多頁 Layout／圖框與單位列印驗證、DXF 互通性擴充、CAD 常用編修（OFFSET／TRIM）及完整 DWG 技術評估。
