# WEB CAD v1.4.0 — 關聯式曲線尺寸標註與來源管理

這一批將 v1.3.0 的半徑、直徑、弧長、圓弧角度標註升級成**可選擇追蹤來源**的 CAD 圖元。來源修改時連動，不需手動改標註文字。它只涵蓋 CIRCLE／原生 ARC 的四種曲線測量，**不涵蓋 DLI/DAL 線性尺寸**或完整 AutoCAD 尺寸關聯功能。內部世界單位仍是 mm。

## 1. 建立關聯式曲線標註

1. 先選一個 CIRCLE 或 ARC，右側「曲線尺寸標註」預設勾選「建立後自動追蹤來源（推薦）」。
2. 使用 **DRA** 半徑、**DDI** 直徑，或在 ARC 上使用 **DAN** 圓弧角度、**DAR** 弧長。
3. 點選文字／標註線的位置，或在 CAD 指令列鍵入絕對座標 X,Y。新尺寸會記錄來源物件 ID，圖元內儲存可復原的幾何快照與標註樣式。
4. 後續選來源圓，在右側「精確半徑」輸入 60cm，原本 R500 應立即顯示 R600，直徑則為 Ø1200。
5. 若來源是 ARC，修改起訖角度或半徑後，DAN 更新到最新弧角；DAR 重新用半徑 × 弧度跨度計算真弧長。

例如原生 ARC 半徑 500、0°→180°，DAR 為約 ⌒1571（小數精度 0）；把終角改成 90° 時，角度標註從 180°→90°，弧長標註從約 1571→785（mm）。

**每次編修只記一筆 Undo**：例如改來源半徑，圓和所有關聯的尺寸會一起更動；按一次 Ctrl+Z 可以整組恢復，Redo 再一起更新。移動或旋轉來源時，文字位置會跟隨中心與弧角調整，並盡量維持文字相對圓周的原有距離。文字本身仍能獨立移動。

## 2. 解除、重新關聯與舊圖相容

在新標註前取消勾選「建立後自動追蹤來源」，即可建立不連動的**獨立快照**。從 v1.3.0 或更早版本儲存的曲線尺寸圖元仍維持獨立快照；新版不會強制把它們接到附近的圓上。

選取已有關聯的曲線標註，右側可看到「已關聯來源」與來源 ID。點「解除關聯，保留目前尺寸」就能停止追蹤，舊數值與標註位置保留不變。

如果要把舊的快照或其他曲線尺寸重新連到來源：

1. 在畫布使用 **Shift+點選**，恰好選取「一個 curveDimension 曲線標註」以及「一個 CIRCLE／ARC 來源」。
2. 右側「物件資訊」按「重新關聯：所選曲線＋尺寸標註」。
3. 成功後會套用新來源的半徑、圓心與弧角，文字位置則維持原本設定，之後再次修改來源時會自動更新。

**相容性檢查：** 半徑／直徑可連 CIRCLE 或 ARC；角度／弧長只可連真正 ARC。不允許來源指向不存在的 ID、錯誤圖元或自身；鎖定／隱藏的尺寸圖層不允許修改它的關聯。

## 3. 刪除來源、複製與 Undo 的保護

- **刪除來源圓或圓弧**：關聯尺寸不會悄悄繼續指向失效 ID，而是立即解除來源並標記 `orphaned`；維持最後數值，右側顯示「來源已刪除或變得不相容」警告。此後尺寸是**過期的凍結快照**，必須人工重新量測或重新關聯，不能用於施工定位。
- **變更來源圖元類型**：例如與角度／弧長標註相連的 ARC 被替換成 CIRCLE，也同樣解除連結並提示來源不相容。
- **Undo／Redo**：同一筆來源刪除及凍結是一個歷史步驟；Undo 還原來源與原關聯，Redo 則恢復失聯狀態。
- **複製來源＋尺寸**：選取兩者一起 COPY 時，複製出的尺寸會對應複製出的圓／圓弧 ID；改變複製圓不會影響原圓標註。
- **只複製尺寸**：複製品仍追蹤原有來源；可以再使用 Shift 同選新曲線與複製尺寸，重新關聯。
- **只移動已關聯的標註**：只移動文字／引線位置，內部量測圓心仍會固定在原來源上，避免文字移動造成偽造尺寸；同時移動來源和標註不會發生二次位移。

## 4. 儲存、匯入與出圖

- **WEB CAD 原生 JSON**：維持 document version 1、模型 mm；關聯式曲線尺寸額外保存 `sourceId`，失聯者保存 `orphaned:true`。匯入時檢查來源存在且模式相容，如果幾何快照與來源不一致，會依實際來源重新校正數值；已存在的 v1.3.0 非關聯式快照不被改動。
- **DXF AC1015**：匯出仍只保存可見 LINE/ARC/LWPOLYLINE/TEXT，無法保存 WEB CAD 專有的來源 ID 與關聯；當圖中有關聯尺寸時顯示**關聯失效警告**。重新匯入 DXF 後不會恢復原生關聯式尺寸，請保留 .webcad.json 做主檔。
- **SVG／PLOT／PDF**：由已更新的關聯幾何向量輸出，實際毫米與 A3/A4 固定比例不改。若圖面有**可見的失聯尺寸標註**，比例出圖面板會警示有幾個凍結數值需要複核；SVG/PDF 仍可輸出，不能把警示當成自動修復。

## 5. Merge 後人工驗收

1. 原本 CIRCLE R500 → DRA，確認「新標註自動關聯來源」已勾選；在圓的右側「精確半徑」填 60cm，應同時看到來源 R600、標註 R600。
2. 一次 Ctrl+Z，圓與標註同時恢復 R500；一次 Ctrl+Y 恢復 R600；重新整理後關聯仍在。
3. CIRCLE R500 同時建 DRA 與 DDI：改 R600 時，R600 和 Ø1200 同步更新。
4. ARC R500、0°→180° 同時建 DAN 與 DAR：修改終角成 90°，應更新成 90°／約 ⌒785；跨 0° 仍採正向弧度跨度。
5. 只 MOVE 標註，確認文字會移動但測量中心、半徑不變。接著 MOVE 來源，確認尺寸位置也會跟隨。
6. Shift 同選來源＋標註後 COPY，修改複製圓半徑，原始尺寸不可跟著改。
7. 對已關聯標註按「解除關聯」再修改來源，確認數值固定；Shift 選來源與標註重新關聯後，再次編修來源應可追蹤。
8. 刪除來源：右側顯示失聯警告；再 Undo 來源與關聯都還原。開 PLOT 應警示凍結尺寸；匯出 DXF 也必須提示損失。
9. 匯出／匯入 WEB CAD JSON 檢查來源 ID、樣式、位置、值。測試 v1.3.0 舊圖的獨立快照不受影響。

## 目前不支援的部分

這批只解決**同一圖面內 CIRCLE／ARC 的來源 ID 關聯**。線性／對齊 DLI/DAL 仍是由點位定義的幾何快照，**尚無來源圖元的關聯機制**；不能對 LINE 的長度直接產生會自動追蹤的 DLI。其他未完成項目：兩條任意直線的 DIMANGULAR、DWG、原生 AutoCAD 關聯式 DIMENSION DXF 往返、圖塊內幾何參照、跨檔案外部參照，以及完整幾何參數約束。Safari、Firefox、手機與外部 AutoCAD 仍需要人工實機驗收。

測試覆蓋 Vitest 來源同步／UNDO／複製／刪除／原生 JSON／DXF／PLOT 與真實 Chromium 指令列、GUI 欄位操作。本版仍是 2D CAD 原型，不是已完成施工驗證的正式工具。
