# WEB CAD v1.3.0 — 游標旁動態輸入、曲線尺寸標註

> v1.4.0 現在支援**可選擇關聯來源的曲線標註**，本篇 v1.3.0 的「非關聯式」描述是該批次的原始行為；新版操作請讀 [ASSOCIATIVE_DIMENSIONS.md](ASSOCIATIVE_DIMENSIONS.md)。

本版在 Canvas 2D 的毫米模型上增加真正可鍵入的動態距離／角度欄位，以及圓與 ARC 的四種幾何標註。仍屬 CAD 技術原型，不得直接當成施工圖認證工具。

## 1. 動態輸入：距離與角度

1. 在命令列輸入 L、PL、REC、C 或 W，並指定第一點，例如 0,0。
2. 游標旁出現「長度」及「角度」兩個可編輯欄位。可直接點選，或在畫布取得焦點後按 Tab／F2 將焦點移到長度欄位。
3. 在長度欄輸入 350cm、3500mm 或依偏好使用無後綴數字。角度輸入 45，或留空讓程式使用目前滑鼠方向。
4. 依設定按 Space 或 Enter，或點「套用」，便會以原本的繪圖指令建立精確圖元。按 Escape 返回畫布。

範例：LINE 的第一點是 (0,0)，長度 350cm，角度 45°，終點應約 (2474.874,2474.874) mm。

前一版的游標旁動態提示仍保留；既有指令列語法 350cm<45 與 @350cm<45 仍可用。瀏覽器／系統保留快捷鍵不會被這兩個輸入框攔截。

## 2. 四種曲線尺寸標註

先選取單一 CIRCLE 或 ARC，再透過命令列或右側「物件資訊」的「曲線標註」按鈕啟動，最後在畫布點擊標註位置或輸入絕對座標 X,Y。

| 簡碼 | 完整命令 | 允許的圖元 | 標註結果 |
| --- | --- | --- | --- |
| DRA | DIMRADIUS | CIRCLE／ARC | 半徑 R500 |
| DDI | DIMDIAMETER | CIRCLE／ARC | 直徑 Ø1000 |
| DAN | DIMANGULAR | ARC | 起訖逆時針弧角 180° |
| DAR | DIMARC | ARC | 真弧長，如半徑 500 的半圓為 ⌒1571 |

圓弧長度 = 半徑 × 角度跨度（弧度）。例如半徑 500、起角 0°、終角 180°，量得 1570.796... mm；標註小數位數為零時呈現 ⌒1571。跨 0° 的 ARC（350°→20°）僅算正向 30° 弧角。

標註會繪製模型幾何的線段、真圓弧、箭頭和文字，使用現有 DIMSTYLE 的字高、箭頭大小、文字間距及小數精度。建立後可以獨立選取、平移、旋轉、調整文字位置夾點、Undo／Redo。

**重要限制：此版曲線標註是非關聯式「幾何快照」**。建立 R500 標註後，就算將來源 CIRCLE 改成 R600，舊標註也不會自動重新計算。來源幾何更新後，請刪除舊標註再標註，避免尺寸誤判。

DAN 僅支援單一原生 ARC 的弧角，不代表已支援任意兩 LINE 的夾角標註。

## 3. JSON、DXF 與 SVG/PLOT 差異

- WEB CAD 原生 .webcad.json：完整保存新 curveDimension 類型、半徑、中心、弧角、標註樣式及位置；舊版本 WEB CAD 不一定支援讀入含新標註的圖檔。
- SVG／PLOT：向量輸出線段、圓弧、三角箭頭和文字，模型尺寸仍採毫米，紙張排版外接範圍包含標註。
- DXF 2000 AC1015：曲線標註展開成 LINE／ARC／LWPOLYLINE／TEXT 等可見圖元，**匯出時必須提示格式轉換警告**。再次匯入 DXF 後只剩可見圖元，不會變回一個可編輯 curveDimension，這不等於 AutoCAD 原生 DIMRADIUS／DIMANGULAR／DIMARC 互通。
- 沒有實測 AutoCAD GUI、DWG 原生往返、外部中文字型、實體印表及 Safari／Firefox 觸控操作；本版不可視為正式施工定稿軟體。

## 4. Merge 後人工驗收

1. 啟動 LINE、輸入起點，再按 Tab 或 F2 聚焦游標旁欄位，輸入 350cm、90°，結果應是 3500 mm 垂直線；Ctrl+Z 一次復原。
2. 畫 CIRCLE R500，選中圓周後執行 DRA → 指定標註位置，應生成 R500；執行 DDI 應為 Ø1000。
3. 選 ARC 0°→180°、半徑 500：DAR 應得到約 ⌒1571，DAN 應得到 180°。
4. 選 ARC 350°→20°，DAN 應是 30°，DAR 應是半徑乘 π/6，不能顛倒方向。
5. 修改來源 CIRCLE 半徑，確認舊標註**不會**自動更新。檢查鎖圖層、Undo、文字位置夾點。
6. 使用 JSON 保存並重開，尺寸物件仍存在；匯出 DXF 時必須看到格式轉換警告；使用外部 CAD 檢查可見的 LINE／ARC／TEXT。
7. 使用 PLOT 對照紙張比例與標註是否有被裁掉；另外測試繁中輸入法及 browser Space／Enter 行為。

自動驗證：Vitest 幾何與格式測試、Playwright Chromium 真實畫布輸入與標註操作、ezdxf 互換測試及 PDF 物理尺寸稽核。所有測試通過也不等於完成工程精度認證。

後續建議：增加來源幾何與標註的關聯式更新、兩條直線的 DIMANGULAR、真正 DXF 原生半徑／角度標註交換，以及 LWPOLYLINE bulge 曲線。
