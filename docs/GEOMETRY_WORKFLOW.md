# WEB CAD v1.2.0 — 動態尺寸、夾點與精準幾何編輯

> v1.3.0 已新增真正可輸入的游標旁 HUD 和曲線尺寸標註，詳見 [CURVE_DIMENSIONS.md](CURVE_DIMENSIONS.md)。本文保留 v1.2.0 原始驗收範圍作歷史參考。

本批將常見室內設計 CAD 編修操作加入既有的 Canvas 2D 模型。所有幾何、原生 JSON、DXF、SVG 仍採世界座標毫米（mm）；公分只是輸入與顯示偏好。產品仍是技術原型，尚不能視為正式施工圖認證工具。

## 1. 動態距離與角度

先輸入 L 啟動 LINE，再輸入起點（例如 0,0），然後移動游標，會看到浮動提示：相對起點的長度、目前偏好單位及角度。例如「350.00 cm ∠ 45.0°」。

在原有 CAD 指令列可直接輸入：
- 350cm<0：向右建立 3500 mm 的線。
- 350cm<90：向上建立 3500 mm 的線。
- 350cm<45：建立 45°、長 3500 mm 的線，終點約為 (2474.874,2474.874) mm。
- @350cm<45：延續原有的相對極座標寫法。
- 350cm：沿游標目前指向的方向輸入精確長度，不必計算 X/Y。
- F8 正交啟用時，滑鼠會限制為水平／垂直方向。

這一版的動態資訊是「畫布即時提示」，尚不是 AutoCAD 在游標旁可直接輸入的多欄位 Dynamic Input；真正鍵入數值仍在指令列，保留 v1.1.0 的空白鍵／Enter、中文輸入法和公分設定。

## 2. 夾點編輯（Grip）

先選擇一個未鎖定的圖元，畫布會顯示藍色控制點。按住夾點、拖曳、放開後正式更新；途中以青色虛線預覽。一次拖曳只記錄一筆 Undo。

支援範圍：
- LINE：起點、終點以及中點（中點拖曳會平移整條線）。
- POLYLINE：逐點編輯頂點；已閉合時起點及終點同步。
- RECTANGLE：四個角點，以相對角為固定點縮放矩形。
- CIRCLE：拖動圓心，或拖動半徑控制點改變半徑。
- ARC：圓心、半徑點、起始角度與結束角度；弧端點拖曳是改變角度，半徑維持不變。
- TEXT、INSERT：插入點；DIMENSION：起點、終點與尺寸線位置。

在 TRIM／EXTEND／OFFSET 或已選取多個物件的情境中，夾點暫時停用，避免操作衝突。鎖層與隱藏圖層不會顯示可編輯夾點。零長線、矩形寬高塌縮、零半徑或相鄰頂點重合會被拒絕，不會破壞原圖。

## 3. 精確屬性面板

選取單個物件後，右側「物件資訊」區多了「精確幾何編輯」。輸入範例 350cm、125mm、1.2m，也可以在 cm 偏好下直接輸入 350。按 Enter 或離開欄位時寫入，單次修改一次 Undo。

可修改的欄位：
- LINE：起點 X/Y、終點 X/Y、精確線段長度、角度（度）。改長度時保留起點及目前方向；改角度時保留長度及起點。
- RECTANGLE：第一角 X/Y、對角 X/Y、寬度與高度，保留原尺寸方向。
- CIRCLE／ARC：圓心 X/Y、半徑；ARC 原有起訖角度欄位繼續支援。
- TEXT／INSERT：插入點 X/Y。

輸入數值精度為 0.001 mm。修改仍使用現有 CAD 圖元、同一物件 ID，保留顏色、線型與圖層，原生 JSON 版本及 DXF 編碼格式不變。

## 4. OSNAP 鎖點強化

原有端點、中點、圓心與交點以外，新增：
- 象限點：CIRCLE 東／北／西／南的 0°／90°／180°／270°；ARC 僅有實際弧線覆蓋的角度才提供。
- 垂足：繪製第二點（或指定編修第二點）時，以第一點為基準，對可見 LINE／RECT／POLYLINE 的有限直線段求垂線投影。垂足在有限線段之外，不會錯誤吸附延長線。

F3 仍可切換鎖點。已鎖定圖層可作為幾何捕捉參考，但不能修改圖層物件。

## Merge 後驗收

1. L → 0,0 → 350cm<45：LINE 終點應約為 (2474.874,2474.874) mm。
2. LINE 0,0 到 3000,0，選取後拖動藍色端點到 3500,0；應保留原起點，一次 Ctrl+Z 還原。
3. 於右側「精確線段長度」輸入 350cm，應更新為 3500 mm；切換公分顯示時，數值仍正確。
4. 拖動 CIRCLE 半徑夾點，或在右側輸入 60cm，應儲存 R600 mm。
5. 閉合 POLYLINE 移動起始頂點，檢查首尾同步；測試鎖定／隱藏圖層與非法退化幾何。
6. 畫線時接近圓的 90° 象限、另一線段的有限垂足，確認 OSNAP 標示及座標。
7. 匯出／匯入 JSON 與 DXF，核對改動後的模型幾何、原物件 ID 和圖層。真實 AutoCAD GUI、印表機、Safari／Firefox／觸控仍需人工驗收。
