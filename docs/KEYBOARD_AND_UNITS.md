# WEB CAD v1.1.0 — 自訂快捷鍵、空白鍵確認與公分精準輸入

此版本針對使用者提出的三個問題：Space 取代 Enter、網頁與瀏覽器快捷鍵互相衝突，以及輸入 cm 尺寸沒反應。這些是本機 CAD 操作偏好，不改變圖紙使用的毫米世界座標或 DXF 模型。

## 1. 鍵盤確認鍵

點選頁面頂部「設定」→「鍵盤與單位設定」，可以選擇：

- 空白鍵＋Enter（預設）
- 只有空白鍵
- 只有 Enter

在 CAD 指令列輸入 L 然後按空白鍵，可以開始 LINE；輸入 0,0 再按空白鍵指定起點；輸入 300cm,0 再按空白鍵完成一條 3000 mm 的線。

**重要**：TEXT 正在輸入自由文字、BLOCK 正在輸入名稱時，空白鍵是文字空格而不是送出；請使用 Enter 完成這種文字輸入，即使設定了「只有空白鍵」也一樣。中文輸入法 composing 過程不攔截確認鍵。當游標停在一般按鈕或文字欄位時也不會亂執行 CAD 指令。

## 2. 公分與毫米的精確數值

模型座標、原生 JSON 與 DXF **始終採 mm**。輸入時可使用後綴 cm／mm／m，或中文「公分／毫米／公尺」，英文字母大小寫均可。所有數字都換算至毫米，最多保留 0.001 mm。

| 輸入值 | 預設 mm 模式 | 切換預設 cm 模式 |
|---|---|---|
| 30 | 30 mm | 300 mm |
| 30cm | 300 mm | 300 mm |
| 12.34cm | 123.4 mm | 123.4 mm |
| 125mm | 125 mm | 125 mm |
| 1.25m | 1250 mm | 1250 mm |
| 300,150 | (300,150) mm | (3000,1500) mm |
| 300cm,150mm | (3000,150) mm | (3000,150) mm |
| @30cm,10cm | 相對 (+300,+100) mm | 相同 |
| @30cm<90 | 向上 300 mm | 相同 |

使用者可以設定「未加後綴的數字」預設為 cm 或 mm。建議習慣公分的室內設計師改為 cm；舊使用者預設 mm 不變。

適用：LINE、RECT、POLYLINE、WALL、ARC、尺寸標註的絕對與相對座標、距離輸入；OFFSET 距離、FILLET 圓角半徑、CHAMFER 兩側距離。工具列的牆厚與新增文字高度也會依所選輸入單位顯示／編輯。角度值仍使用度，不被長度單位換算。切換設定不會修改已存的圖面。

例：12.34cm 精確換算為 123.4 mm；1.23456cm 以 0.001 mm 模型精度保存為 12.346 mm，並非整數近似。

## 3. 指令快捷鍵編輯

設定對話框內提供 22 個常見 CAD 指令主要簡碼的編輯欄，如 LINE、PLINE、CIRCLE、ARC、MOVE、COPY、ROTATE、OFFSET、TRIM、FILLET、CHAMFER、ERASE、DIMLINEAR。

例如將 LINE 原本的 L 改成 Q，儲存後就能輸入 Q＋空白鍵啟用 LINE；主要簡碼 L 停用，但完整 LINE 文字仍有效。設定存放在瀏覽器 localStorage 的 web-cad:v1:preferences，與圖面檔案獨立，重新整理後保留。若需還原，按「恢復預設」再儲存。

代碼只接受 1–8 個英文字母。若新代碼已被其他 CAD 指令佔用（如 LINE 改成 TR），或使用 SPACE、ENTER、CTRL 等系統保留碼，會顯示錯誤拒絕儲存。此功能屬於自訂**指令文字代碼**，並非任意 OS 全域按鍵錄製器。

## 4. 瀏覽器快捷鍵與 CAD 衝突處理

網頁的鍵盤事件權限無法提升到比作業系統或瀏覽器更高。Ctrl／Command+L（網址列）、T（新分頁）、W（關分頁）、R（重新載入）、S（瀏覽器另存）、F（搜尋）、P（列印）等不由 WEB CAD 攔截；部分按鍵根本不會傳給網頁。

- 畫布或頁面空白焦點：可輸入 CAD 指令字元，Space／Enter 確認；Ctrl／Command+Z／Y、A 為 CAD 復原重做／選取全部。
- 一般輸入框、繁中輸入法、設定視窗：保留正常文字輸入、空格、Ctrl／Command+A、Z、C、V 等，不將編輯文字誤判成 CAD 快捷鍵。
- F3 鎖點和 F8 正交只在 CAD 畫布取得焦點時攔截，普通網頁其他區域不攔截。
- 原先 Ctrl／Command+P 會被 WEB CAD 攔截為 PLOT，v1.1.0 改為讓瀏覽器使用原生列印；需要按比例出圖時請使用畫面頂部的「比例出圖」或輸入 PLOT 指令。
- 點選 CAD 畫布後可使用空白鍵重複指令；按鈕有焦點時，Space 仍維持按鈕本身的原生行為。

## 自動測試及人工驗收

- src/cad/preferences.test.ts 測試精確換算、座標／距離、輸入法、代碼衝突／設定修復、鍵盤事件安全。
- e2e/cad.spec.ts 追加 Playwright 真 Chromium：Space 確認、cm 輸入、簡碼修改與重載保存、衝突拒絕、TEXT 空格、瀏覽器 Ctrl 組合鍵保留。
- GitHub Actions 的 npm test、npm run build、npm run test:e2e 需同時成功才可 Merge。

手動建議：設定「空白鍵＋Enter」，L→Space→0,0→Space→300cm,0→Space，預期 3000 mm；再切換 cm，L→Space→0,0→Space→300,0→Space，應仍為 3000 mm。對 OFFSET 輸入 12.5cm 得到 125 mm 偏移；對 FILLET 輸入 10cm 得 R100。使用繁中 IME 輸入「客廳 主要空間」確認文字空格未誤提交。畫布 F3/F8 與瀏覽器 Ctrl+P、Ctrl+L／T 仍應按預期運作。

目前測試範圍是 Chromium 桌面；尚未涵蓋所有 Safari／Firefox／macOS／Windows 各家 IME、行動觸控及完整施工圖認證。此版本仍屬技術原型。
